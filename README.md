AI Resume Screening Automation

An AI-based web application for screening resumes against job descriptions.

🌐 Live Website

"Click Here to Open the Project" (ai--resume-screening.streamlit.app)

✨ Features

- Upload multiple PDF resumes
- Extract text from PDF files
- Match candidate skills with job requirements
- Calculate resume matching scores
- Display matched and missing skills
- Download screening results as a CSV file

🛠️ Technologies Used

- Python
- Streamlit
- PyPDF
- Pandas

🚀 Run the Project

Install the required packages:

"pip install -r requirements.txt"

Run the application:

"streamlit run app.py"
